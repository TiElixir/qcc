# Benchmark measurements

Generated by `python scripts/benchmarks.py` from the checked-in `examples/benchmarks.c` fixture.

Resource columns are measured from the compiled circuit's `qcc.resource_report` result. `Gates` is the logical netlist operation count; `MCX` is the logical multi-controlled-X count, while the T estimate uses qcc's clean-ancilla Toffoli accounting.

Compile time is the measured wall-clock duration of each real `qcc.compile_c` call, reported in milliseconds to three decimal places. It varies with the host and is not used to infer resource reductions. An O3 compile also lowers the function at O0 so its report can show a measured baseline, and that time is included.

Rows are emitted in the fixed order `add`, `multiply`, `compare`, `popcount`, `is_solution`, with the measured optimizer levels adjacent. O0 is the Bennett compute-copy-uncompute baseline; O2 adds SSA simplification, gate cancellation, and clean-ancilla reuse to it; O3 is the dataflow synthesizer. Reductions are measured, not inferred.
